# Repository Reconnaissance

Use this workflow before significant work when current repository state matters.

1. Read `AGENTS.md` and `.ai/STATE.md`.
2. Check the branch and `git status`.
3. Identify and protect unrelated in-flight changes.
4. Read recent relevant commits when useful.
5. Identify the affected project or projects.
6. Inspect the existing implementation before proposing a change.
7. Inspect relevant tests.
8. Read only the canonical documents relevant to the task.
9. Summarize the current state, affected components, existing behavior, risks, and smallest proposed scope.

Do not embed SmartMoney architecture details here. Reference the canonical documents instead.
